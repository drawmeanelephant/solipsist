# Solipsist — Brand assets

Visual identity for the project. The mark: **one mind reading its own
mail** — an open envelope whose flap is also an eyelid over a calm
watching eye, sealed with a single copper dot. Deep indigo, warm
paper-white, one copper accent.

## Files

| File | What | Size |
|------|------|------|
| `solipsist-icon-1024.png` | App icon / avatar. Square, reads at small sizes. | 1024×1024 |
| `solipsist-icon-1600.png` | Higher-res master of the icon. | 1600×1600 |
| `solipsist-banner.png` | Wide banner for README / social / site headers. | 2352×1008 |

## Palette

- Indigo night — `#1e1b4b`-ish deep indigo (background)
- Paper white — warm off-white (the envelope)
- Copper seal — `#b87333`-ish (the single accent dot)

## Notes

- These are project graphics (README, site, social), not the shipped
  macOS `AppIcon.appiconset` — swapping the app's icon is a separate,
  deliberate decision (it changes the product people see in their Dock).
- If the site ever wants a matching Open Graph card, start from
  `solipsist-banner.png` and the palette above.
