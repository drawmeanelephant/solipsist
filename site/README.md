# Solipsist Project Site

The public documentation and project site for Solipsist, hosted at
**https://solipsist.filed.fyi** (Cloudflare Pages project `solipsist`,
Pages alias `solipsist.pages.dev`).

## Profile & Content

- `boris.json`: Plain static-site profile (schema version 1, target `site`,
  output `dist`, input `content`).
- `content/`: Closed-frontmatter Markdown pages (`index.md`, `mission.md`,
  `roadmap.md`, `architecture.md`, `dogfood.md`).
- `themes/boris/`: the site theme — layouts (`main.html`, `home.html`),
  `footer.html`, and `assets/` (CSS, favicons, Open Graph card). The home
  layout is selected for `id:index` via a build-time layout rule; inner pages
  use the default layout. The theme ships Boris's first-party
  rendered-search UI (`_boris/search/`), so the site is fully searchable with
  no vendored JavaScript. Favicons are copied from the app icon set and the
  Open Graph card is generated by `scripts/make-og-card.py`. See
  `themes/boris/README.md`.
- `robots.txt`: copied to the build root by the deploy workflow / `make
  check-site` (Boris only writes theme assets + pages).

## Building

```bash
cd site
../boris/zig-out/bin/boris build --profile boris.json \
  --layout-rule default id:index themes/boris/layouts/home.html \
  --sitemap --site-url https://solipsist.filed.fyi
```

The single public target is synthesized as the CLI target `default`. The
`site` Make target runs the same command with the same flags.

`make check-site` builds the site, copies `robots.txt` into `dist/`, and runs
`scripts/check-site-links.py` — a static check that every internal link and
anchor resolves and every `sitemap.xml` entry has a published file. CI runs
the same check before deploying.

## Deployment to Cloudflare Pages

`.github/workflows/deploy-site.yml` builds the site with Boris (pinned to the
same `afterparty` engine commit the app bundles) and publishes `site/dist/`
to Cloudflare Pages on push to `main` when `site/**` changes.

Manual deployment:

```bash
cd site
../boris/zig-out/bin/boris build --profile boris.json \
  --layout-rule default id:index themes/boris/layouts/home.html \
  --sitemap --site-url https://solipsist.filed.fyi
cp robots.txt dist/robots.txt
python3 ../scripts/check-site-links.py --root dist --base-url https://solipsist.filed.fyi
npx wrangler pages deploy dist --project-name solipsist
```
