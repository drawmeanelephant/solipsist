# Solipsist site theme

The site's theme lives at `site/themes/boris/` and is picked up by the
`boris build --profile boris.json` invocation (the product default theme
root, resolved relative to the profile workspace).

## Shape

```text
themes/boris/
  README.md
  layouts/
    main.html      # default docs/article layout (all inner pages)
    home.html      # id:index → landing layout (selected via --layout-rule)
  footer.html      # {{footer}} fragment — rendered as the window status bar
  assets/
    css/boris.css
    favicon/       # favicon-32/128 + apple-touch-icon, copied from the app icon set
    og/og-card.png # 1200x630 social card, generated by scripts/make-og-card.py
```

Both layouts share the same stylesheet and the first-party Boris
rendered-search UI (`data-boris-search-*` hooks + inline script, exactly the
consumer Boris ships with its default theme; no external resources, no
vendored JavaScript). Both layouts carry favicon links (via `asset-url`) and
static Open Graph / Twitter card meta pointing at the deployed domain.

## The window

The page renders as a simulated three-pane macOS window mirroring the app's
own spatial model (see `docs/HARNESS.md` §2 — sources | play | drawer):

- **Titlebar** — traffic lights, brand, and a GitHub action, over a blur
  material.
- **Left — sources sidebar.** Mail-style nav rows for the site's pages plus
  the search field at the top. This is where `{{nav}}` and the search UI
  live.
- **Middle — play.** The boxed article (`{{content}}`), breadcrumb, and
  article-level relations/backlinks. The center column scrolls on its own,
  like the app's play pane.
- **Right — inspector drawer.** Grouped-form sections: "On this page"
  (`{{toc}}`) and "In this section" (`{{children}}`). Empty sections are
  hidden at runtime; a small inline scrollspy marks the section you are
  reading (`is-active`).
- **Status bar** — the `{{footer}}` fragment, styled as the app's status
  bar.

The layout is Starlight's three-column docs shape wearing the ergonomics of
the application: materials, traffic lights, selection tints, grouped-form
drawer, independent pane scrolling. On narrow viewports the window stacks —
nav collapses to pill rows, the drawer drops below the article.

## Provenance

Original CSS. The boxed-article vocabulary borrows the shape of Boris's
first-class
[`engineering`](https://github.com/drawmeanelephant/boris/tree/main/themes/engineering)
theme (Primer-inspired, per its README); the window chrome mirrors the app's
SwiftUI chrome (`NavigationSplitView` + `.inspector` in
`Sources/Chrome/MainWindow.swift`). The palette, type, hero, feature cards,
and status bar are Solipsist's own. No third-party bytes are shipped.

## Layout selection

The home layout is selected by an explicit layout rule because the profile
schema's `layout_rules` are not executed by the pinned compiler slice:

```bash
boris build --profile boris.json \
  --layout-rule default id:index themes/boris/layouts/home.html \
  --sitemap --site-url https://solipsist.filed.fyi
```

The target synthesized from the single public target is named `default`.
